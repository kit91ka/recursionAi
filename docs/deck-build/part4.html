ЭТАП ПИЛОТА

Проверка подключения DeepSeek

Порядок проверки

  1. Зафиксировать источник API
  2. Developer API key ≠ подписка chat/app
  3. Base URL https://api.deepseek.com, model id deepseek-chat / deepseek-reasoner
  4. Smoke test «return only OK»
  5. Одна мелкая правка
  6. Только потом — Figma-сценарий

Типовые причины ошибок

  • Подписка вместо API key
  • Неверный model id
  • Не тот base URL
  • Key не в той переменной
  • Нужен OpenRouter/LiteLLM
  • Network/proxy
  • Модель без tool use

Критерий успеха

  • DeepSeek подключается без обходов
  • Setup воспроизводится за 15–30 минут

  • Изменения проходят build
  • Diff ревьюится без ощущения переписанного проекта
