Проверка фактов

Важные находки при проверке

Roo Code закрыт ARCHIVED

Репозиторий RooCodeInc/Roo-Code в состоянии archived, последний пуш 2026-05-15. Развитие остановлено — в пилот брать не рекомендуется.

Hermes: источник под вопросом проверить

Официальный сайт — hermes-agent.nousresearch.com; домен hermes-agent.ru похож на зеркало/локализацию. Перед использованием подтвердить аутентичность источника.

Звёзды GitHub недостоверны метод

Точные счётчики звёзд в окружении проверки оказались недостоверными — активность оцениваем по дате последнего коммита и флагу archived.

DeepSeek — не дифференциатор факт

DeepSeek предоставляет OpenAI-compatible API, поэтому любой инструмент с поддержкой OpenAI-compatible endpoint умеет с ним работать. Это общий факт, а не преимущество отдельного инструмента.
