Ключевые сноски

  • *2 Расширения VS Code/JetBrains: код локально, но модель обычно облачная (DeepSeek API). Полный self-hosted дают только Hermes и OpenHands.
  • *6 Нативной Figma-интеграции нет ни у кого. Реальный путь — vision по скриншоту плюс сторонний MCP-сервер Figma (например Framelink/Figma MCP). Aider без MCP — только скриншот/экспорт вручную.
  • *7 Aider: контроль через git — правки идут коммитами, легко смотреть и откатывать.
  • *8 OpenHands: diff виден в треде/логе, но модель «одобри каждое действие» слабее, чем у Cline.
  • *16 Hermes: мощный набор фич, но требует серверного setup, проверки безопасности и подтверждения аутентичности источника (.ru vs nousresearch.com).
  • *17 OpenHands: самый тяжёлый setup (Docker/sandbox), для ежедневной frontend-работы может быть избыточен.
