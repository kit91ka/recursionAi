Задача

Замена Claude Code для Angular multi-agent workflow

Эта версия раскрывает методику: какие роли оценивали кандидатов, какие подметрики вошли в score, как считалась итоговая оценка и почему stars не равны пригодности для команды.

Основа: `docs/claude_alternatives_multiagent_review.md` + GitHub API на 2026-06-14.

Методика · что означают числа

Score не является benchmark-результатом: это desk-review fit score, который должен быть подтверждён пилотом

Что оценивали

  • Заявленные возможности в официальных docs/GitHub.
  • Соответствие 10 критериям multi-agent замены Claude.
  • Пригодность для Angular/Nx, Figma, design-system и CI workflow.
  • Риски внедрения, безопасности, поддержки и ownership.

Что не оценивали

  • Не запускали одинаковый live benchmark на вашем репозитории.
  • Не мерили фактический pass rate build/test/lint.
  • Не считали latency/cost по реальным задачам.
  • Не проводили security review MCP-интеграций.
Интерпретация: score помогает выбрать shortlist для пилота, а не заменить пилот.
Формула · как считалась оценка

Итоговый score = среднее четырёх ролевых оценок; stars идут отдельно и не входят в формулу

RoleScore = average(подметрики роли)
TotalScore = average(AgentProtocol, AngularWorkflow, FigmaDesignSystem, PlatformSecurityEconomics)
GitHubStars = traction signal, вес 0%

Agent protocol

5 подметрик: роль, протокол, координация, tool-use, контекст/память.

Angular workflow

7 подметрик: Angular/Nx, правила, поиск файлов, planner split, diff, review, lint/test/build.

Figma / DS

5 подметрик: Figma, MCP/screenshot, preview, design-system/a11y, security posture.

Platform

6 подметрик: observability, security, economics, rollout speed, internal support, product support.

Шкала · rubric 0-5

Оценка ставилась по пригодности к роли, а не по общей популярности инструмента

ScoreИнтерпретацияТипичный смысл для пилота

4Хороший fit, есть отдельные риски или требуется настройка.Годится для shortlist.

0Неприемлемо для production rollout.Hard stop.

Решение · целевая схема

Не один победитель, а связка ролей с разными уровнями риска

Cline

Основной IDE-agent: ежедневная разработка, Figma handoff, Angular multi-file changes, тесты.

OpenHands

Platform-agent: автономный SDLC workflow, issue → PR, sandbox, self-host/enterprise сценарии.

Вспомогательные роли

  • Continue: PR checks/governance.
  • Aider: tactical CLI fixes.
  • Hermes: R&D runtime.
  • Roo Code: exclude.
