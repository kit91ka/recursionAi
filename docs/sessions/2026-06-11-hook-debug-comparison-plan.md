## Запрос
1. Посмотреть `docs/claude_alternatives_comparison_plan.txt` и предложить схему сравнения альтернатив Claude (сетка свойств, за/против) — без установки всех инструментов.
2. Разобраться, почему не сработал хук `continue-on-api-error.js` при ошибке `API Error: The socket connection was closed unexpectedly`.
3. Убрать мёртвый хук.

## Что сделано
- Прочитан план сравнения (Hermes Agent, Aider, Roo Code, Cline, Continue, OpenHands). К предложению схемы сравнения вернуться не успели — разговор ушёл в дебаг хука.
- Диагностирована причина несрабатывания хука (см. ниже).
- Удалён мёртвый блок `StopFailure` из `.claude/settings.json`. Остались рабочие `SessionStart` и `Stop`.
- `continue-on-api-error.js` пока не удалён — жду подтверждения пользователя.

## Решения и причины
- **`Stop` не запускается при обрыве сокета**: транспортная ошибка обрывает ход аварийно, а `Stop` срабатывает только при штатном завершении ответа. Инжектить «продолжай» нечему.
- **`StopFailure` — несуществующее событие** Claude Code (валидные: PreToolUse, PostToolUse, UserPromptSubmit, Notification, Stop, SubagentStop, SessionStart, SessionEnd, PreCompact). Блок был мёртвой конфигурацией → удалён.
- **Ложное срабатывание**: `continue-on-api-error.js` ищет строку `socket connection was closed unexpectedly` в хвосте транскрипта. Обсуждение самой ошибки в чате заставило хук матчиться на собственный текст и вставлять «продолжай» на каждой остановке. Дополнительный аргумент за удаление.
