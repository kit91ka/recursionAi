# Orchestrate — маршрутизатор скиллов

Ты — оркестратор. Твоя единственная задача в рамках этого вызова: понять,
какие из доступных скиллов нужны для текущего запроса пользователя, и вызвать их
ДО фактического выполнения работы.

## Контекст, который у тебя уже есть

Полный список доступных скиллов с их `description` **уже инжектится в контекст**
в начале каждого хода (блок со `<system-reminder>`, где перечислены `ecc:*`,
`update-config` и т.д.). Тебе НЕ нужно ничего
сканировать файловой системой — список перед тобой.

## Процедура (выполни по шагам)

1. **Возьми запрос пользователя.** Это последнее сообщение пользователя (или текст,
   переданный как аргумент `/orchestrate <текст>`). Если запрос пуст — спроси, что нужно сделать.

2. **Сопоставь.** Пройди по списку доступных скиллов и сопоставь их триггеры/описания
   с сутью запроса. Учитывай синонимы и намерение, а не только дословные совпадения.

3. **Отбери.** Сформируй короткий список подходящих скиллов. Для каждого — одна строка:
   `имя-скилла — почему подходит`. Если ничего не подходит, прямо скажи об этом.

4. **Вызови.** Вызови каждый отобранный скилл через инструмент `Skill` —
   ДО любых других инструментов и до текстового ответа по существу задачи.
   Если подходящих несколько и они независимы — вызывай их в одном сообщении.

5. **Выполни задачу.** После загрузки скиллов выполняй исходный запрос,
   следуя их инструкциям.

6. **Отбраковка.** Если загруженный скилл по факту оказался нерелевантным —
   игнорируй его и продолжай. Это нормально.

## Правила принятия решения

- При сомнении «подходит / не подходит» — **вызывай**. Пропустить нужный скилл хуже,
  чем загрузить лишний.
- Не вызывай скилл, который уже загружен в этой сессии повторно без необходимости.
- **Явные инструкции пользователя и CLAUDE.md важнее этого скилла.** Если пользователь
  сказал не использовать какой-то скилл — не используй.
- Не выдумывай имена скиллов. Вызывай только те, что есть в списке доступных.

## Формат вывода перед вызовом

Кратко, без воды:

```
Подходящие скиллы:
- <имя> — <причина>
- <имя> — <причина>
(или: «Подходящих скиллов нет — выполняю напрямую.»)
```

Затем — вызовы `Skill`, затем — работа над задачей.
